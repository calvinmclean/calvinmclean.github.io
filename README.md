## Local development

Install Go and [Hugo Extended](https://gohugo.io/installation/), then run:

```sh
task serve
```

`articles/<slug>/article.md` and `article.json` remain the canonical post source. `task generate-content` creates the ignored Hugo page bundles that power the local site and GitHub Pages build.

> [!NOTE]
> This repository uses [`article-sync`](https://github.com/marketplace/actions/article-sync) GitHub Action to post articles to [DEV](https://dev.to/calvinmclean).
